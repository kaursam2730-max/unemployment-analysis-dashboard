# 📊 India Unemployment Analytics Dashboard

An interactive data analytics dashboard for exploring unemployment trends across different regions of India.

## 🚀 Live Dashboard

👉 https://unemployment-analysis-dashboard-cztzrbmgqswk7vawymrp9b.streamlit.app/

## 📌 Project Overview

This project analyzes unemployment data in India and presents the findings through an interactive Streamlit dashboard.

The dashboard allows users to explore unemployment rates, labour participation, employment trends, and regional differences using interactive filters and visualizations.

## ✨ Features

- 📈 Unemployment trend analysis
- 🗺️ Region-wise unemployment comparison
- 👥 Employment trend analysis
- 📊 Labour participation analysis
- 🔎 Interactive region and area filters
- 📅 Date range filtering
- 📋 Filtered dataset preview
- ⬇️ Download filtered data as CSV
- 📱 Interactive web dashboard

## 🛠️ Tech Stack

- Python
- Pandas
- Plotly
- Streamlit
- Data Visualization
- Exploratory Data Analysis (EDA)

## 📂 Dataset

The project uses the **Unemployment in India** dataset containing information such as:

- Region
- Date
- Frequency
- Estimated Unemployment Rate (%)
- Estimated Employed
- Estimated Labour Participation Rate (%)
- Area

## 📊 Dashboard KPIs

The dashboard provides:

- Average Unemployment Rate
- Highest Unemployment Rate
- Average Labour Participation Rate
- Total Records
